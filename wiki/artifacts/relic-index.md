## What Makes a Relic Different From an Artifact

| | Artifact | Relic |
|---|---|---|
| Rarity | Rolls randomly on spawn | Fixed — always the same rarity |
| Quantity per match | Multiple of same type can spawn | One per match maximum |
| Historical basis | Era-appropriate but generic | Tied to a specific anchor event |
| Universe variants | Stat shifts ±15% | Visual and lore shifts, same rarity |
| Spawn location | Seeded random positions | Fixed zone per anchor (always in the most dangerous area) |
| Minimap | Standard artifact icon | Distinct relic icon — glows differently |

## SPAWN RULES (applies to all relics)

- Maximum **one relic per match** — the rarest relic available for that anchor spawns
- Relic spawn location is always in the **highest-danger zone** of the map for that anchor
- Relic has a **distinct minimap icon** — a glowing diamond shape, different from standard artifact circles
- Relic **cannot be duplicated** in the Simulation Layer — `isSimulacrum` is always false for relics
- Relic **trade value** is always 3× the standard Mythic/Legendary/Epic trade value for that era
- Relic **does not reset on disconnect** — returns to spawn with a boss, rarity does not bump
- Relic **guardian scales** with player count — solo players face a weaker guardian but have no support
- Relic **award is randomized** among eligible team members within 20m at extraction — see [[relic-fairness-system]]
- Solo extraction requires **elite gear** to be viable — 20-second channel, repeat broadcasts every 3s without gear
